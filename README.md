### 🚀 Featured: [JARVIS](https://github.com/borhanslm/jarvis-agents)

<a href="https://github.com/borhanslm/jarvis-agents"><img alt="JARVIS" src="https://raw.githubusercontent.com/borhanslm/jarvis-agents/main/docs/screenshots/home.png" width="100%"></a>

A local Windows app that turns two AI coding agents into a team: a **builder** writes the code, a **reviewer** tests it and reports bugs, and they loop until the reviewer approves.

- Works with **Claude Code, Codex, DeepSeek** or any Anthropic / OpenAI-compatible API — for either role
- Everything runs on your own computer; keys stay encrypted locally
- Per-file diffs with one-click revert, checkpoints, sub-agents, usage dashboard, 12 themes
- Auto-updates from GitHub Releases

[**⬇️ Download for Windows**](https://github.com/borhanslm/jarvis-agents/releases/latest/download/JARVIS-Setup.exe) · [Docs (Persian)](https://github.com/borhanslm/jarvis-agents#readme)
